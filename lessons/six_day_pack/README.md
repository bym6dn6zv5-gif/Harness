# 接下来六次学习：Harness 入门实验

每天约 2 小时，不绑定日历日期。材料已经准备，学习状态由你实际学习后再更新。
你已经运行过第一课的五步演示和原有 13 项测试；本学习包从这段经历继续，先复盘，再逐步加功能。

## 从哪里开始

主项目固定在：

```text
D:\python\File of python\Harness开发
```

每次打开 PowerShell，先进入项目目录：

```powershell
Set-Location -LiteralPath 'D:\python\File of python\Harness开发'
```

然后打开当天讲义，一天只推进一份。六天的参考实验均使用模拟模型，不联网，不调用付费 API，
也不需要额外安装软件。第 4、6 天会在项目内的 `.harness` 中生成记录；这些文件被 Git 忽略。

| 学习日 | 讲义 | 学完后能说明 | 自己补的代码 |
| --- | --- | --- | --- |
| 1 | [工具成功与失败](day01.md) | 错误在哪一层发生，为什么也要回传 | 根据工具结果返回状态字符串 |
| 2 | [工具注册与参数模型](day02.md) | 工具名字怎样找到函数，参数怎样被检查 | 查找函数、调用参数模型校验 |
| 3 | [有上限的循环](day03.md) | 模型调用怎样继续，何时停止 | 停止条件与工具反馈消息 |

## 三类文件的用途

1. **参考实现**：`mini_harness/lesson01_cases.py` 与 `lesson02.py` 到 `lesson06.py`，已经可以运行。
2. **你的练习**：`exercises/day01_starter.py` 到 `day06_starter.py`，留有需要自己补的函数。
3. **提示和答案**：[hints-and-answers.md](hints-and-answers.md) 与 `exercises/answers.py`，卡住时可分级查看。

不要把参考实现的检查通过当作自己已经写会了。每次都留下运行输出和一段自己的解释。
聊天时我会按你实际的理解继续，一次处理一个小问题；不需要先把六天都自学完。

## 怎样检查

检查参考实现及检查器本身：

```powershell
& .\.venv\Scripts\python.exe -X utf8 -m pytest -q
```

当前参考检查为 60 项，包含原有 13 项。未填写的练习不会被这条命令自动收集。
当天写完练习后，显式运行对应检查器，例如：

```powershell
& .\.venv\Scripts\python.exe -X utf8 -m pytest .\exercises\check_day01.py -q
```

`starter` 尚未填写时，这条命令会出现 `NotImplementedError`，含义是“练习还没写”，不需要重装环境。
填写时把对应的 `raise NotImplementedError(...)` 替换为自己的实现。
默认测试不会替你验证练习答案；请运行当天的 `check_dayXX.py`。

检查器完全可见，用于学习反馈；它们不是隐藏考试，也不构成实习招聘的评分标准。
参考答案已经用相同的检查器核对。运行核验情况见 [verification.md](verification.md)。

## 每天的两小时

- 25 分钟：读当天概念，先预测输出。
- 55 分钟：运行实验、找对应代码、填写小练习。
- 20 分钟：运行当天检查，复盘一个错误。
- 20 分钟：做当天 Python / 计算机基础练习，或带着输出回来聊天。

如果练习没有通过，可以继续留在同一天；先处理第一个失败，不必赶进度。
