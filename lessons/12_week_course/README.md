# 12 周完整课程：从工具调用到编程 Agent 项目答辩

[回仓库首页](../../README.md) · [按时间查课](../../docs/study-calendar.md) · [按主题查资料](../../docs/reference-index.md)

起点是能写小型 Python 项目，每天约 2 小时。目标是独立实现、排错、评测并讲解一个小型编程 Agent。
本目录按 **72 次动手课 + 12 次周复盘** 编排，不绑定日历日期。前面的九天小实验可当作预习材料，
不等于已经完成对应周次。学习者实际进度见 [进度表](progress.md)，目前全部待学习。

## 怎样区分教材和已经运行的程序

已可直接运行的参考代码是 `mini_harness/lesson01.py` 至 `lesson09.py`，以及第一课场景模块。
完整项目中的 `run`、`resume`、`eval` 是下列课程要求你逐步实现的目标接口，目前入口尚未完成。
讲义中标作“目标”“验收预期”的结果不是现成的运行记录。
后续实验需要的 Docker、模型服务、SDK 和 MCP 依赖，也没有在这次备课中自动安装或付费调用。

每次学习按以下节奏：25 分钟概念和小例子，55 分钟实现一个功能，20 分钟测试和失败记录，
20 分钟算法或系统基础。每周第 7 天只做复盘与补漏；验收不过就先留在本周。

## 来聊天时，我们怎样推进

告诉我“第 W 周第 D 天”，再发一条命令、一个错误或你的解释即可。
我会先让你预测或复述，再给一个小提示；你提交代码和结果后，我们一起判断是否过关。
不要一次把整周答案复制进项目。核心循环、恢复和评分三个模块要能关掉答案独立修改。

周末用五句话复盘：做了什么、怎样验证、失败在哪里、为什么这样设计、下次改什么。
学习记录由你的实际提交和讲解更新；教材写齐不会自动把任何一课标为完成。
