# 源码贯穿课程的 12 周

每周从这张表取一小段，与当周 Python 功能同时学习。每次增加 15—25 分钟阅读，
从原有概念时间中分配，不额外要求每天整晚读 Rust。
表中“继续追踪”是待完成作业；当前已核对范围见各主讲义和版本索引。

| 周 | 主教材任务 | 必须提交的理解证据 |
| --- | --- | --- |
| 1 | claw run 的请求、执行、回传；Codex build_tool_call | 自己画一次调用，分清三位参与者 |
| 2 | 对照两种工具结果消息；继续追具体 handler 参数校验 | 名称、参数、call id、结果逐字段映射 |

## “吃透”的分层验收

第一层：不用术语背诵，解释模型、宿主程序、操作系统分别做什么。
第二层：给定源码入口，追到真正读写文件的位置，列出对象字段的变化。
第三层：给定一个失败日志，判断问题可能来自模型、Harness、环境或任务需求，并补一项证据。
第四层：独立实现小改动，例如一个只读工具、恢复冲突规则、摘要证据字段。
第五层：设计实验，证明改进是否有效，承认任务简单、样本小和模型费用统计误差。

通过前一层再进入后一层。当前第一课已有运行证据；新教材所有源码精读仍为待学习。
