## 每天的安排

- 25 分钟：概念与少量官方资料。
- 55 分钟：实现或运行一个小功能。
- 20 分钟：测试、执行记录和失败分析。
- 20 分钟：算法，以及 HTTP、进程、异步和数据库基础。

每周推进 6 天，复盘 1 天；周验收未通过时，先修复基础，再压缩扩展内容。

## 最终成果

1. 可按文档运行的 Python 编程 Agent 项目。
2. 固定任务集、自动评测和实验报告。
3. 架构说明、已知限制与失败案例。
4. 基于真实完成工作的简历描述和面试讲解。

评分测试在 Agent 可修改的工作区之外。比较基线与改进版时固定模型、任务和预算，
报告通过率、耗时、token 用量及至少 5 个失败案例；最终保留集每任务重复运行 3 次。

第一课使用模拟模型，不产生 API 费用。后续首次真实调用的本地预算上限暂设人民币 100 元，
使用前再核对服务商、实际计费和限额执行方式；达到上限后暂停付费调用。

这些是学习验收标准。当前环境、第一课和 [六天入门实验](../lessons/six_day_pack/README.md) 已落地，
学习者仍按实际完成情况推进。六天先通过小实验预习概念，后续周路线中的完整项目能力尚待按课实现。
