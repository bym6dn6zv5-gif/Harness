## 后续怎样维护

- 新增一课：先加入对应时间表，再补主题索引；保留旧课编号与链接。
- 更新源码教材：记录新 commit 和所读范围，不悄悄替换旧实验版本。
- 补充真实评测：写明运行日期、模型、预算与原始结果，和教学材料校准分开。
- 更新学习进度：依据学习者实际代码、输出与讲解，单独修改进度表。
- 每次增加资料后，在此表末尾追加一行真实日期和提交入口。
